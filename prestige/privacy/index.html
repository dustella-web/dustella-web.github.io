개발자 Dustella · Android 앱 환생기 (com.prestige.rebirth) 1.0.0

수집 및 이용

이 버전은 계정 가입과 광고 없이 동작합니다. 환생기는 기기에서 게임 정보를 수집해 개발자 서버로 전송하거나 자동으로 제3자와 공유하지 않습니다.

기기에 저장하는 정보와 삭제

닉네임, 진행 중인 생, 완료 기록과 설정은 게임 저장과 이어하기를 위해 기기 내 앱 전용 저장소에 보관합니다. 게임 정보는 앱 설정에서 ‘모든 데이터 삭제’를 선택하거나 앱을 삭제할 때까지 기기에 보관됩니다.

선택한 앱으로 결과 공유

결과 카드를 공유하면 사용자가 Android 공유 화면에서 선택한 앱에 카드가 전달됩니다. 공유한 사본은 해당 앱 또는 받는 사람이 관리합니다.
